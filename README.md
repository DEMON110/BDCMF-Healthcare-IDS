Overview
This repository contains the complete implementation, experiments, and reproducibility package for the paper:
> *A Blockchain-Driven Consent Management Framework with Temporally Validated, Explainable Machine Learning for Intrusion Detection in IoT-Healthcare Ecosystems*
The framework integrates:
Healthcare IoT IDS: Trained on ToN-IoT with temporal validation, leak-free SMOTE, and probability calibration
Blockchain Anomaly Detection: Trained on Elliptic Bitcoin dataset with AUPRC-focused evaluation
Consent Smart Contracts: Deployed on Sepolia Ethereum testnet with gas/throughput measurements
Explainability: SHAP-based global and local explanations with 15-feature ablation for edge deployment

Installation
1. Clone the repository
```bash
git clone https://github.com/[author]/BDCMF-Healthcare-IDS.git
cd BDCMF-Healthcare-IDS
```
2. Create virtual environment
```bash
conda create -n bdcmf python=3.10.12
conda activate bdcmf
```
3. Install dependencies
```bash
pip install -r requirements.txt
```

Reproduction Pipeline
Execute in order:
Step	Script	Output	Time
1	`python src/preprocess_toniot.py`	`data/processed/toniot_*.csv`	~5 min
2	`python src/preprocess_elliptic.py`	`data/processed/elliptic_*.csv`	~3 min
3	`python src/baseline_benchmark.py`	`results/tables/table_10_cv.csv`, `table_11_holdout.csv`	~45 min
4	`python src/bayesian_optimize.py`	`results/tables/table_13_tuned.csv`	~35 min
5	`python src/calibrate_model.py`	`results/tables/table_15_calibration.csv`	~10 min
6	`python src/bootstrap_ci.py`	`results/tables/table_14_bootstrap.csv`, `table_19_elliptic_bootstrap.csv`	~20 min
7	`python src/shap_explain.py`	`results/tables/table_16_ablation.csv`, `table_17_shap.csv`, `table_19_shap.csv`	~25 min
8	`python src/ensemble_methods.py`	`results/tables/table_17_ensemble.csv`	~15 min
9	`python src/deploy_sepolia.py`	`results/tables/table_9_sepolia.csv`	~30 min*
*Requires Sepolia testnet ETH and Infura/Alchemy API key.

Smart Contracts
Deployment (Sepolia)
```bash
export SEPOLIA_RPC="https://rpc.sepolia.org"
export PRIVATE_KEY="0x..."
export INFURA_KEY="..."

python src/deploy_sepolia.py --contract ConsentRegistry --network sepolia
```
Contract Functions
`registerPatient(did, pubKey)` — binds DID to Ethereum address
`requestConsent(patientDID, dataType, purpose, duration)` — creates Requested record
`grantConsent(requestId)` — patient approves (Granted)
`revokeConsent(consentId)` — patient revokes (Revoked)
`accessData(consentId, queryHash)` — requester accesses data if Granted + not expired
`auditLog(consentId)` — returns immutable event log
